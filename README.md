# 벤처나라 공공조달 시장의 참여업체 수와 금액 집중도(HHI) 분석

조달청 벤처나라 9년치 거래실적으로 "시장이 커진 만큼 기회도 넓게 퍼졌는가"를 검증한 5인 팀 프로젝트 중, 본인이 담당한 **RQ2(참여업체 수·금액 집중도) 분석** 코드를 정리한 저장소입니다.

> **담당:** RQ2 분석·시각화 · **팀원 담당:** RQ1·RQ3·RQ4, 데이터 전처리(기준은 팀 전체 논의로 결정)
>
> 이 저장소에는 본인 담당인 RQ2의 코드와 결과를 담았습니다. 전처리 노트북은 RQ2 결과를 재현하기 위해 팀 공동 전처리 코드를 함께 포함했습니다.
>
> 분석 기준을 정한 과정, AI 분석 초안을 바로잡은 내용 등 **상세 과정은 블로그**에 정리했습니다 → [블로그 글](https://blog.naver.com/haeniv_v/224445329981)

## 핵심 결과

| | |
|---|---|
| **약 15배** | 물납 기준 참여업체 2017년 46개 → 2024년 693개 (2025년 513개로 처음 감소) |
| **HHI 168** | 2025년, 9년 중 최저. 2018년 이후 매년 1,000 미만(비집중) |
| **15개 중 12개** | 산업군 단위로 보면 2025년 HHI 1,000 이상. 산업 안은 여전히 집중 |

![연도별 참여업체 수와 HHI](figures/python/rq2_yearly_firms_hhi.png)

- 분석 기준: 2017~2025년, 물납(실제 납품) 실적 30,172행, 업체는 벤처업체번호로 식별
- 집중도 감소는 2017→2018년 급락(HHI 1,701 → 334)에 기댄 것으로, 2017년을 빼면 추세가 유의하지 않습니다. 이후로는 저집중이 유지됐습니다.
- 2025년에 빠진 업체 358개의 2024년 금액 중앙값은 0.16억 원으로, 남은 업체(0.76억 원)보다 작았습니다.

![산업군별 연도 HHI](figures/python/rq2_industry_hhi_heatmap.png)

- 2019~2025년 매년 업체 5개 이상인 15개 산업군 중, 지속적으로 분산된 산업은 교육·복지용품과 구조물·공조 설비 2개뿐입니다.

## 시사점

- **운영자:** 전체 HHI(168)만 보면 분산된 것처럼 보이지만 산업군 대부분은 중간~고집중입니다. 산업군별 HHI를 정기 지표로 볼 필요가 있습니다.
- **진입 업체:** 구조물·공조(업체 118개, HHI 656)처럼 분산된 산업은 경쟁 업체가 많고, 농업용 기계(11개, 5,713)처럼 집중된 산업은 소수 업체가 금액 대부분을 차지합니다.

기록상 실적에서 확인한 범위 안의 해석이며, 원인은 이 데이터만으로 확정하지 않았습니다.
